# SaaS Dashboard

A simple project management dashboard built with Next.js and Supabase.  
You can list, filter, search, sort, add, edit, delete projects, and view some useful statistics.

---

## Features

- List all projects in a clean table
- Search projects by name or assigned member
- Filter projects by status (active, on hold, completed)
- Sort by budget (ascending/descending)
- Add new projects
- Edit or delete existing projects
- Dashboard statistics:
  - Total budget (sum of all projects)
  - Percentage of completed projects
  - Farthest deadline with project name

---

## Tech Stack

- Next.js 15 (App Router, React 18)
- Supabase (Postgres database, API, Auth-ready)
- Tailwind CSS for styling
- Preline for UI components
- TypeScript
